# Install Cube Timer

Requires Android 8.0 or newer. The app works offline and requests no permissions.

1. Copy `CubeTimer-1.0.0.apk` to your phone, for example through Google Drive or a USB file transfer. Alternatively, download the APK from the private GitHub release while signed in as the repository owner.
2. Open the APK on the phone in Files or Downloads.
3. If Android asks, open Settings and enable **Allow from this source** for the app opening the APK.
4. Go back and tap **Install**, then **Open**. You can disable **Allow from this source** again after installation.

Menu names vary between phone manufacturers. Keep Google Play Protect enabled. Developer mode and USB debugging are not needed for this installation method.

# Use the timer

Tap anywhere inside the app to start. The screen turns red. Tap again to stop; the screen turns green and keeps the result visible. The next tap starts a new solve from zero.

The timer keeps running if you switch apps or Android closes the process. The last stopped result survives reopening the app. Restarting the phone cancels a running solve. The screen stays awake while timing. Android system bars retain their normal behavior.

The first version stores the current or last solve only. It does not include history or settings.

# Updates

Install a newer APK over the existing app. Future builds must use the same application ID and signing key. Uninstalling the app removes its saved result.
